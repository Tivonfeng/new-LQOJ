🛠️ 二、知识讲解（20分钟）

🧰 2.1 四个基础数据类型

整数类型（int）

✨ 整数类型 ✨

  • 没有小数部分的数字
  • 可以表示：年龄、数量、得分等
  • 示例：1、2、3、-10
print(10)    # 打印 10 这个整数
print(95)    # 打印 95 这个整数
浮点数类型（float）

💫 浮点数类型 💫

  • 有小数部分的数字
  • 可以表示：长度、重量、价格等
  • 示例：3.14、2.5、-0.5
length = 2.5  # 将 2.5 这个浮点数，赋值给 length 这个变量
price = 9.99  # 将 9.99 这个浮点数，赋值给 price 这个变量
布尔值类型（bool）

🎯 布尔值类型 🎯

  • 只有两个值：True（真）和False（假）
  • 可以表示：开关状态、条件判断等
  • 示例：True、False
is_raining = True  # 将 True 这个布尔值，赋值给 is_raining 这个变量
is_sunny = False   # 将 False 这个布尔值，赋值给 is_sunny 这个变量
字符串类型（str）

🤖 字符串类型 🤖

  • 由字母、数字和符号组成的文本
  • 可以表示：名字、句子、网址等
  • 示例："Hello"、'Python'
name = "Alice"           # 将 "Alice" 这个字符串，赋值给 name 这个变量
sentence = 'I love coding!'  # 将 'I love coding!' 这个字符串，赋值给 sentence 这个变量

🧰 2.2 数据类型的转换

💫 自动转换 💫

  1. 除法运算自动转为浮点数：10 / 5 = 2.0
  2. 不同精度运算自动转为高精度：1.0 + 1 = 2.0

💫 手动转换 💫

# 转换为整数
int('123')      # 结果为123
int('123.123')  # 结果为123

# 转换为浮点数
float('123')    # 结果为123.0

# 转换为字符串
str(123)        # 结果为'123'

🚀 三、变量学习（15分钟）

😎 3.1 什么是变量

💡 变量的作用：

  • 存储信息
  • 给数据一个有意义的名字
  • 方便在程序中使用

💖 3.2 变量的命名规则

🎯 命名规则：

  • 只能使用字母、数字和下划线
  • 不能以数字开头
  • 区分大小写
  • 不能使用Python关键字

🌟 3.3 变量的赋值

# 普通赋值
name = "neo"

# 多个变量赋相同值
a = b = c = 1

# 多个变量赋不同值
a, b, c = 1, 2, "neo"

# 常量（约定俗成）
PI = 3.14
