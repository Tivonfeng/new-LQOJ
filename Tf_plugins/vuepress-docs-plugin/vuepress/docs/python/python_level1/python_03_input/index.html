🛠️ 二、知识讲解（20分钟）

🧰 2.1 获取单个输入

✨ 一行一个数据 ✨

# 获取用户输入并保存到变量中
name = input()   # 获取一行输入，赋值给name变量

# 获取多行输入
a = input()      # 第一行输入
b = input()      # 第二行输入

🧰 2.2 获取多个输入

💫 一行多个数据 💫

# 例如输入：1 2 'hello' 4.5
# 使用split()方法分割输入
ls = input().split(' ')  # 结果：['1','2','hello','4.5']

# 通过下标访问各个元素
num1 = int(ls[0])    # 第一个数字
num2 = int(ls[1])    # 第二个数字
num3 = ls[2]         # 字符串
num4 = float(ls[3])  # 浮点数

🧰 2.3 输入类型转换

🎯 类型转换方法 🎯

# 转换为整数
number = int(input())    # 输入"123" → 123

# 转换为浮点数
height = float(input())  # 输入"1.75" → 1.75

# 智能转换（根据输入自动判断类型）
num = eval(input())      # 输入"123" → 123
                        # 输入"1.23" → 1.23
                        # 输入"'hello'" → 'hello'

注意事项

  1. input()函数返回的永远是字符串类型
  2. 在OJ系统中，input()函数不要加提示语
  3. 使用split()分割时，注意分隔符的选择

🚀 三、实践环节（15分钟）

😎 3.1 基础练习

# 练习1：获取用户名字
name = input()
print("你好，" + name + "！")

# 练习2：获取两个数字并计算和
a = int(input())
b = int(input())
print("两数之和是：", a + b)

💖 3.2 进阶挑战

# 挑战：获取一行包含多个数字的输入，计算它们的和
numbers = input().split(' ')
sum = 0
for num in numbers:
    sum += int(num)
print("总和是：", sum)
